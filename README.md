# Portfólio Pessoal - Backend Developer

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória profissional, projetos, habilidades técnicas e formas de contato.

📍 **Acesse o site online:** [https://analaurams.github.io/portifolio/](https://analaurams.github.io/portifolio/)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização moderna com CSS Grid, Flexbox, variáveis CSS e design responsivo.
- **JavaScript (Vanilla)**: Interatividade da página e animações de exibição ao rolar (*scroll reveal*).
- **Font Awesome**: Ícones vetoriais para redes sociais e seções do site.
- **GitHub Pages**: Hospedagem e deploy contínuo do projeto.

---

## ✨ O que foi feito

- **Seção Hero Lado a Lado**: Apresentação principal com foto de perfil e texto introdutório organizados em layout lado a lado.
- **Sobre Mim**: Breve resumo sobre atuação e foco em arquitetura backend.
- **Linha do Tempo (Experiência)**: Apresentação estruturada das experiências profissionais anteriores e atuais.
- **Habilidades Técnicas**: Cards interativos destacando o ecossistema Java, Spring Boot, Docker, Bancos de Dados e APIs.
- **Contato**: Links diretos e clicáveis para e-mail, LinkedIn e GitHub.
- **Design Responsivo**: Adaptação automática do layout para dispositivos móveis e desktops.
